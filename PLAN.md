# IceHacks execution plan — solo entrant

Official deadline: 15 November 2026 at 18:00 PST, which is 16 November at 09:00 in Vietnam. Internal submission target: 16 November at 06:00 Vietnam time.

## Scope freeze

IceGuard supports a public JavaScript or TypeScript GitHub repository, four narrow checks, evidence and coverage display, one deterministic patch, and optional visitor-owned Ollama review. Do not claim full security coverage, AST analysis, autonomous agents, or automatic PR creation in the submission.

## Priority order

1. Public GitHub repository and public app URL.
2. Stable demo video and complete Devpost submission.
3. A working local Ollama segment, only if a model can be installed and tested without delaying the first two priorities.
4. Additional checks or visuals, only after the submission package is complete.

## Required assets

- Public GitHub repository URL.
- Public deployed app URL.
- Public YouTube, Vimeo, or Youku video URL, under three minutes.
- Devpost write-up with problem, architecture, challenges, learning, and next steps.
- Built-with and AI-assistance disclosure.

The Devpost site contains inconsistent wording about video and cash awards. Prepare the video and repository to satisfy the stricter stated requirements. Verify actual prize terms with organizers if they affect decisions.
